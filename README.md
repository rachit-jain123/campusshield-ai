# CampusShield AI

CampusShield AI is a machine learning based security system that detects malicious URLs, text and documents.

## Features
- URL threat detection
- Text threat analysis
- Document scanning

## Tech Stack
Python, FastAPI, Machine Learning, React, Node.js

## Installation

Backend

pip install -r requirements.txt
uvicorn app.main:app --reload

Frontend

npm install
npm run dev
